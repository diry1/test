CAR SPOTTER - LOCAL BROWSER APP

1. Extract the entire ZIP to a folder on your PC. Do not run inside the ZIP.
2. On Windows, double-click "Start Car Spotter.bat".
3. The browser opens automatically. Keep the terminal window open.
   If necessary, manually open http://localhost:8000.

Requires Python 3. No IDE or additional Python packages are needed.
If Python is missing, install it from https://www.python.org/downloads/windows/
and enable "Add python.exe to PATH" during installation.

On macOS/Linux: run python3 start.py in this folder.

Do not open index.html directly. It must be served by the launcher.
Your sightings and photos are saved in this browser on this computer.
Use the same browser and http://localhost:8000 address each time.
Clearing site data removes sightings. Export a backup in My garage.
Reference photos are placeholders. No cloud sync is implemented.
